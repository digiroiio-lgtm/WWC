# WWC

Statik SEO bilgi mimarisi aşağıdaki alanları içerir:

- Ana sayfalar ve program sayfaları
- Ülke bazlı içerik kümeleri (`/ulkeler/{ulke}/...`)
- Dönüşüm odaklı landing page’ler
- E-E-A-T güven sayfaları
- Blog içerik URL mimarisi
- Sitemap index + alt sitemap dosyaları
- `robots.txt` kural seti
- Temel Schema.org JSON-LD örnekleri (Organization, LocalBusiness, EducationalOrganization, Person, Article, FAQPage, BreadcrumbList, Review, Service, WebSite)
